# Khảo sát người dùng

Thư mục này lưu biểu mẫu và kết quả khảo sát (mục tiêu 20–30 người).

## Biểu mẫu câu hỏi

1. Bạn mất bao lâu để quyết định ăn gì mỗi bữa?
2. Bạn thường dựa vào yếu tố nào: giá, khoảng cách, khẩu vị, thời gian?
3. Bạn đang dùng ứng dụng nào để chọn món?
4. Điều gì làm bạn khó chịu nhất khi chọn món?
5. Bạn có muốn một ứng dụng gợi ý ngẫu nhiên theo tiêu chí không? Vì sao?
6. Bạn mong muốn tính năng nào nhất (lưu món, lịch sử, chọn theo nguyên liệu, đặt giao)?
